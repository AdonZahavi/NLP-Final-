## Cross-cutting notes for the experiments

- **Sentiment is heavily imbalanced** (~66% pos / ~31% neg / ~3% off-topic): report macro-F1, and stratify the ~500-example subset (issue #4).
- **Sentiment 'neutral' is actually off-topic** — prompt wording must say off-topic, not neutral.
- **HebNLI train is machine-translated**; only the test split is human-verified — evaluate on test only.
- **HeQ contexts are long** — dominant driver of API cost (see scripts/estimate_costs.py).
- The sentiment `morph` variant is gold pre-segmented morphemes: a useful upper-bound/sanity reference for our own segmentation in issue #6.
